# Sales Analysis Dashboard | Power BI
## Project Overview
The Sales Analysis Dashboard is an interactive Business Intelligence project built using Power BI, SQL, and DAX to analyze sales performance, profitability, customer trends, and product performance across multiple regions and years. This dashboard enables users to explore business insights through dynamic filtering, KPI monitoring, and visual analytics, helping stakeholders make data-driven decisions efficiently.

## Business Problem
#### Businesses often struggle to identify:
  - High-performing products
  - Most profitable regions
  - Sales growth trends
  - Revenue-driving categories
  - Customer purchasing patterns

## Project Objectives
  - Analyze yearly sales and profit trends
  - Identify top-selling products and categories
  - Monitor regional sales performance
  - Track business KPIs and growth metrics
  - Enable dynamic filtering for detailed analysis
  - Improve business decision-making using data visualization


## Dashboard Features
  1) KPI Tracking
     - Total Sales
     - Total Profit
     - Total Orders
     - Year-over-Year Sales Comparison
  2) Interactive Filters
     - Product Category
     - Year
     - Month
     - Vendor
  3) Data Visualizations
     - Sales Trend Analysis
     - Product Performance Analysis
     - Top Selling Products
     - Country-Wise Profitability
     - Yearly Sales Comparison
     - Regional Sales Insights
  4) Interactive Analytics
     - Dynamic slicers
     - Drill-down analysis
     - Cross-filtering between visuals
     - Interactive dashboard navigation

## 🔹 Technical Stack
  - Power BI – Data modeling, DAX calculations, and interactive visualizations.
  - SQL – Data extraction and transformation.
  - Data Cleaning & Preparation – Ensuring data accuracy and consistency before analysis.

## Key Business Insights
  - USA generated the highest overall profit contribution.
  - Classic Cars category produced the highest sales revenue.
  - Sales performance peaked in 2004 before declining in 2005.
  - Top-selling products significantly contributed to total revenue growth.
  - Regional sales analysis helped identify high-performing markets.
